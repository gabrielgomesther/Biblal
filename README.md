# Suíte Bíblica Unificada: Bíblia Cronológica 365 & Teologia Bíblica — Kit Completo PWA (GitHub Pages)

Este pacote unifica em uma única aplicação web progressiva (PWA 100% offline) os dois aplicativos originais:
1. **A Bíblia Cronológica em 365 Dias (12 Fases / 1.189 Capítulos na Ordem Histórica da TNM)**
2. **Grade Curricular de Teologia Bíblica (7 Eixos / 28 Fases / 112 Módulos / 827 Questões / 481 Fontes / 336 Práticas)**

## Principais Melhorias da Versão Unificada
- **Painel Hoje & Visão Geral Integrada**: Reúne os indicadores das duas trilhas, o card de *Próxima Leitura Cronológica (365)*, o card de *Módulo de Teologia em Andamento* e os mapas visuais interativos das 12 Fases e dos 7 Eixos.
- **Ponte Bidirecional (Leitura 365 ↔ Teologia)**: Cada Fase da Bíblia 365 exibe atalhos diretos para as Fases de Teologia Bíblica que aprofundam aquele período histórico (e vice-versa).
- **Busca Global Instantânea (`🔍` ou `Ctrl+K`)**: Pesquisa simultaneamente nos 365 dias da Bíblia Cronológica, nos 112 módulos de Teologia, nas 827 perguntas/respostas e nas notas do Caderno.
- **Migração Automática e Mesclagem de Backups (`.JSON`)**: Importa automaticamente qualquer progresso salvo anteriormente no mesmo navegador (`jw_biblia_cronologica_365_v1` e `jw_theology_pwa_v2_state`) e permite restaurar/mesclar backups `.json` antigos de qualquer um dos dois apps sem sobrescrever a outra trilha.
- **Compatibilidade com Links Antigos no GitHub Pages**: Inclui `index.html`, `Biblia_365_e_Teologia_Unificado_PWA.html`, `Biblia_Cronologica_365_Dias_PWA.html` e `Curriculo_Teologia_Biblica_PWA.html` para que qualquer favorito antigo abra diretamente a nova suíte unificada.
